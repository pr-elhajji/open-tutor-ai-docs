# 👩‍🎓 Premiers pas en tant qu'étudiant

Bienvenue sur OpenTutorAI ! Ce guide vous aidera à démarrer
avec la plateforme étape par étape.

![Page d'accueil OpenTutorAI](/img/student-guide/home.png)

---

## Étape 1 — Inscription et création de votre compte

Cliquez sur **S'inscrire** pour créer un nouveau compte.

![Page de connexion](/img/student-guide/Login.gif)

Choisissez votre rôle : **Étudiant**

![Choisir votre rôle](/img/student-guide/role.gif)

:::info Remplissez vos informations
- Entrez votre **Prénom** et votre **Nom**
- Entrez une **adresse e-mail** valide
- Choisissez un **mot de passe** dont vous vous souviendrez
- ✅ N'oubliez pas de cocher **"J'accepte les conditions d'utilisation"**
- Cliquez ensuite sur **Créer un compte**
:::

![Créer un compte](/img/student-guide/signup.gif)

---

## Étape 2 — Accéder à votre tableau de bord étudiant

Après vous être connecté, vous arrivez sur votre **Tableau de bord**.

![Tableau de bord](/img/student-guide/dashboard.png)

:::tip Ce que vous pouvez voir sur votre tableau de bord
- Vos **supports** (sessions d'apprentissage)
- Votre **progression**
- Vos **devoirs**
:::

---

## Étape 3 — Créer un support d'apprentissage

1. Cliquez sur ➕ **Support**

![Cliquer sur Support](/img/student-guide/support-btn.gif)
   Puis cliquez sur **Créer mon support**
![Cliquer sur Créer mon support](/img/student-guide/support-btn_Create.gif)

2. Remplissez le **titre** et une courte **description** de votre objectif

![Formulaire de support](/img/student-guide/support-form.png)

:::info Exemple
- **Titre :** Apprendre les bases de Python pour débutants
- **Description :** Je veux apprendre les fondamentaux de la programmation Python, notamment les variables, les boucles, les fonctions et la résolution de problèmes de base. Mon objectif est de créer des programmes simples et de comprendre les concepts essentiels de la programmation.
- Choisissez votre **matière**
- Cliquez sur **Continuer**
:::
![Exemple de formulaire de support](/img/student-guide/support-form_Example.gif)

3. Téléchargez un fichier si disponible **(PDF / Word / PPT)** — ou ignorez

![Télécharger un fichier](/img/student-guide/Upload_a_file.gif)

4. Définissez votre **objectif d'apprentissage**

![Objectif d'apprentissage](/img/student-guide/learning_objective.jpg)

5. Sélectionnez votre **niveau** (Primaire / Collège / Lycée / Université)

![Niveau](/img/student-guide/level.jpg)

6. Choisissez votre **langue** et la **durée**

![Langue et durée](/img/student-guide/language_duration.png)

7. Cliquez sur **Continuer**

---

## Étape 4 — Commencer à apprendre

1. Vérifiez toutes vos informations : Titre, Objectif, Niveau
2. Cliquez sur **Démarrer l'apprentissage**

![Vérifier le support](/img/student-guide/review.gif)

3. Choisissez votre expérience de chat :

![Choisir votre modèle](/img/student-guide/chat-Modele.gif)
![Choisir l'expérience](/img/student-guide/chat-choice.gif)

4. Choisissez vos modes de chat :
:::tip Deux modes disponibles
- 💬 **Chat Texte** — Rapide, efficace, supporte les blocs de code
- 🤖 **Chat Avatar** — Avatar 3D avec voix et animations
:::
![Modes de chat](/img/student-guide/Chat_modes.gif)

---

## 🎉 Vous êtes prêt !

Vous pouvez maintenant commencer à apprendre avec votre tuteur IA.
Posez des questions, téléchargez des documents

![Démarrer l'apprentissage](/img/student-guide/start_learning.png)

et suivez votre progression directement depuis votre tableau de bord.

![Progression](/img/student-guide/progress.png)
