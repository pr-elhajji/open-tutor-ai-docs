🚀 **Bienvenue aux Contributeurs !** 🚀

Votre intérêt à contribuer à Open TutorAI est grandement apprécié. Ce document est là pour vous guider tout au long du processus, en veillant à ce que vos contributions améliorent efficacement le projet. Rendons Open TutorAI encore meilleur, ensemble !

## 💡 Contribuer

Vous cherchez à contribuer ? Formidable ! Voici comment vous pouvez aider :

### 🌟 Directives de contribution au code

Nous acceptons les pull requests. Avant d'en soumettre une, veuillez :

1. Ouvrir une discussion concernant vos idées [ici](https://github.com/R2D-dev/open-tutor-ai-CE/discussions/new/choose).
2. Suivre les normes de codage du projet et inclure des tests pour les nouvelles fonctionnalités.
3. Mettre à jour la documentation si nécessaire.
4. Rédiger des messages de commit clairs et descriptifs.

### 🛠 Bonnes pratiques pour les PR de code :

1. **PR atomiques :** Assurez-vous que vos PR sont petites, ciblées et traitent un seul objectif ou une seule tâche. Cela facilite la revue de code et limite les risques d'introduire des problèmes non liés. Si la portée des modifications devient trop importante, envisagez de les diviser en PR plus petites et logiquement indépendantes.
2. **Respecter la convention de code existante :** Assurez-vous que votre code est conforme aux normes et pratiques de codage existantes du projet.
3. **Éviter les dépendances externes supplémentaires :** N'incluez pas de dépendances externes supplémentaires sans discussion préalable.
4. **Approche indépendante du framework :** Nous visons à rester indépendants du framework. Implémentez les fonctionnalités par vous-même autant que possible plutôt que de dépendre de frameworks ou bibliothèques externes. Si vous avez des doutes ou des suggestions concernant cette approche, n'hésitez pas à en discuter.

Merci de contribuer ! 🚀

### 📚 Documentation et Tutoriels

Aidez-nous à rendre Open TutorAI plus accessible en améliorant la documentation, en rédigeant des tutoriels ou en créant des guides sur la configuration et l'optimisation de l'interface web.

### 🌐 Traductions et Internationalisation

Aidez-nous à rendre Open TutorAI disponible à un public plus large. Dans cette section, nous vous guiderons à travers le processus d'ajout de nouvelles traductions au projet.

Nous utilisons des fichiers JSON pour stocker les traductions. Vous pouvez trouver les fichiers de traduction existants dans le répertoire `src/lib/i18n/locales`. Chaque répertoire correspond à une langue spécifique, par exemple, `en-US` pour l'anglais (États-Unis), `fr-FR` pour le français (France) et ainsi de suite. Vous pouvez vous référer aux [Codes de langue ISO 639](http://www.lingoes.net/en/translator/langcode.htm) pour trouver le code approprié pour une langue spécifique.

Pour ajouter une nouvelle langue :

- Créez un nouveau répertoire dans le chemin `src/lib/i18n/locales` avec le code de langue approprié comme nom. Par exemple, si vous ajoutez des traductions pour l'espagnol (Espagne), créez un nouveau répertoire nommé `es-ES`.
- Copiez le(s) fichier(s) de traduction en anglais américain (depuis le répertoire `en-US` dans `src/lib/i18n/locale`) vers ce nouveau répertoire et mettez à jour les valeurs des chaînes au format JSON selon votre langue. Assurez-vous de préserver la structure de l'objet JSON.
- Ajoutez le code de langue et son titre respectif au fichier de langues à `src/lib/i18n/locales/languages.json`.

### 🤔 Questions et Retours

Vous avez des questions ou des retours ? Rejoignez notre [communauté Discord](https://discord.gg/BTQtE2deEm) ou ouvrez une issue. Nous sommes là pour vous aider !

### 🚨 Signaler des problèmes

Vous avez remarqué quelque chose d'anormal ? Vous avez une idée ? Consultez notre [onglet Issues](https://github.com/R2D-dev/open-tutor-ai-CE/issues) pour voir si cela a déjà été signalé ou suggéré. Si ce n'est pas le cas, n'hésitez pas à ouvrir une nouvelle issue. Lorsque vous signalez un problème, veuillez suivre nos modèles d'issue. Ces modèles sont conçus pour garantir que tous les détails nécessaires sont fournis dès le départ, nous permettant de traiter vos préoccupations plus efficacement.

:::important

- **Conformité au modèle :** Veuillez noter que le non-respect du modèle d'issue fourni, ou le fait de ne pas fournir les informations demandées, entraînera probablement la fermeture de votre issue sans autre considération. Cette approche est essentielle pour maintenir la gérabilité et l'intégrité du suivi des problèmes.

- **Le détail est essentiel :** Pour garantir que votre problème soit compris et puisse être traité efficacement, il est impératif d'inclure des détails complets. Les descriptions doivent être claires, incluant les étapes à reproduire, les résultats attendus et les résultats réels. Le manque de détails suffisants peut entraver notre capacité à résoudre votre problème.

:::
