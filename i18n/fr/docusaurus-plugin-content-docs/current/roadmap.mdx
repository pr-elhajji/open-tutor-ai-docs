# 🗺️ Feuille de Route

OpenTutorAI est une plateforme d'apprentissage open source alimentée par l'IA qui vise à démocratiser l'accès aux outils éducatifs intelligents.  
Notre mission est de donner aux apprenants et aux éducateurs les moyens d'utiliser des retours adaptatifs, des assistants personnalisés et des espaces d'apprentissage collaboratifs.

## 🛠️ Prochaine Étape – v1.1.0 (T3 2025)

- [ ] Personnalisation de l'avatar (nom, ton, voix)
- [ ] Affichage de la mémoire du tuteur par session
- [ ] Améliorations UI/UX (infobulles, disposition plus claire)
- [ ] Tableau de suivi de l'engagement (clics, feedback, abandons)
- [ ] Définir et exposer des API pour les extensions externes
