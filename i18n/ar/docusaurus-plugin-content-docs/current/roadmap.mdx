# 🗺️ خارطة الطريق

OpenTutorAI هي منصة تعليمية مفتوحة المصدر مدعومة بالذكاء الاصطناعي تهدف إلى إتاحة الأدوات التعليمية الذكية للجميع.  
مهمتنا هي تمكين المتعلمين والمعلمين من خلال التغذية الراجعة التكيفية، والمساعدين الشخصيين، ومساحات التعلم التعاونية.
